# AllStunts Rigging Asset Manager — Build 2026.07.30.2

This build uses a white background, black interface artwork, and includes 1,612 inventory rows extracted from the supplied master asset register.

## GitHub Pages upload
Upload every file and folder in this package directly to the repository root. `index.html` must be visible at the top level of the repository, not inside another folder.

Then choose **Settings → Pages → Deploy from a branch → main → /(root)**.

The lower-left corner of the running site displays **BUILD 2026.07.30.2** so you can confirm GitHub is showing this version.

The package deliberately unregisters older service workers and clears old browser caches because those can make GitHub Pages continue displaying a previous build.
